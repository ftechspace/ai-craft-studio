# Taste profile

The creator's profile lives next to this file:

1. **`profile.md`** — the real, personal profile (git-ignored, so it stays on this machine). **Read it if it exists.**
2. **`profile.example.md`** — the shared starting point: the structure, the reference-study method, and an example
   house style (intimate real-life vlog storytelling). Use it when `profile.md` doesn't exist yet, and copy it to
   `profile.md` to start a creator's own profile.

## Keeping it current
- After every reaction from the creator ("too short", "not creative enough", "keep the natural sound"), add it to
  "What they've told us" with the date and the project.
- When the creator shares reference videos, study them with `references/STUDY-BRIEF.md`, save each analysis as
  `references/analysis-<id>.md` (git-ignored: other people's work stays local) and add a row + the lessons to the
  profile's reference table and house style.
- Record each finished project and the creator's verdict in "Our past work and verdicts".
- Standing rules the creator states ("don't shorten", "no names") go at the top and override everything else.
